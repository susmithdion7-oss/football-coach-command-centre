## Feature Notes

### Coach HQ Dashboard

Goal: make Dashboard feel like Coach Mission Control. It should show the coach what matters today: next session, player priorities, match context, tactical board activity, and quick actions.

### Player Feedback

Goal: connect coach observations to long-term player growth. Start with simple training feedback and development timeline before complex analytics.

### Session Design Studio

Goal: make session planning feel like a creative professional workspace, not a giant form. Prioritize session dashboard, create wizard, activity editor, diagrams, reflection, and output.

### Tactical Board Presentation

Goal: make Tactical Board feel like a pitch-side explanation tool. Improve object workflow, board library, selected-object controls, presets, and presentation mode.

### Match Centre

Goal: connect match preparation and reflection to next training focus. Avoid turning it into heavy fixture administration.

### Reports

Goal: summarize player development, session history, tactical board use, and future match feedback. Reports should support coaching decisions.

### PDF

Goal: produce coach-facing session output that can be printed or shared. Keep output readable before making it visually elaborate.

### Import / Export

Goal: protect localStorage users before cloud sync exists. Export/import should include players, sessions, boards, identity, lineup, tactics, assignments, and draft state when appropriate.

### AI Assistant

Goal: future server-side assistant that uses real coaching context. Start with read-only suggestions and editable drafts only after backend exists.

### Backend

Goal: future safe sync and storage, not immediate. First document stable localStorage data shapes and migration path.

### Mobile / PWA

Goal: make the app easier to use on phones/tablets after desktop workflows are strong. Do not let mobile work break dense coaching workspaces.
